# ELASK Windows Companion Service

This local service enables the **ELASK Web Assistant** to safely communicate with your Windows laptop.

## Security Architecture & Guarantees
1. **Localhost Only**: Binds exclusively to `127.0.0.1:9123`. It is never accessible from external networks.
2. **Token Authentication**: Every sensitive request must provide a valid `X-ELASK-TOKEN`.
3. **Whitelist Execution Only**: ELASK **never** executes arbitrary shell commands or code generated by AI models. Only apps explicitly approved by the owner in the settings list (`Microsoft Edge`, `Notepad`, `Calculator`, `VS Code`, etc.) can be launched.
4. **URL Sanitation**: Browser open actions only accept `http://` and `https://` protocols, exclusively launched in Microsoft Edge.
5. **Full Audit Log**: Every action is saved to an on-device activity log viewable in the companion and the web HUD.

## Setup Instructions (Windows)
1. Ensure Node.js (v18+) is installed on your Windows machine.
2. Open a terminal or PowerShell in this `companion` directory:
   ```cmd
   cd companion
   node server.js
   ```
   Or simply double-click `start-companion.bat`.
3. The service will start listening on `http://127.0.0.1:9123`.
4. Return to the ELASK Web HUD and click **"Connect Companion"** or open the **Settings > Windows Companion** panel.
5. The status indicator will turn **ONLINE (CYAN)**.

## Supported Commands
- *"ELASK, open Microsoft Edge"* -> Launches `msedge.exe`
- *"ELASK, open github.com in Edge"* -> Opens validated URL in Edge
- *"ELASK, open Notepad"* -> Opens `notepad.exe`
- *"ELASK, open Calculator"* -> Opens `calc.exe`
- *"ELASK, zoom in / zoom out"* -> Sends Ctrl+Plus / Ctrl+Minus to target window
- Hand gesture pinch / spread -> Sends zoom commands with debounce
